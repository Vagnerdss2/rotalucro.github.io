Política de Privacidade

Última atualização: Setembro de 2026

Bem-vindo ao RotaLucro. Sua privacidade é extremamente importante para nós. Esta Política de Privacidade descreve como lidamos com as informações no seu dispositivo.

1. Coleta de Dados

O RotaLucro foi projetado para ser um aplicativo de uso offline e privado. Nós não coletamos, não armazenamos e não transmitimos nenhum dado pessoal, financeiro ou de localização para servidores externos.

Todos os dados inseridos por você (como valores de corridas, quilometragem, plataforma, custos de combustível e manutenção) são armazenados localmente no seu dispositivo através de um banco de dados interno (SQLite).

2. Uso de Dados

Os dados permanecem exclusivamente sob seu controle. O aplicativo utiliza essas informações apenas para calcular suas métricas de lucro, gerar relatórios e fornecer o dashboard de desempenho dentro do próprio app.

3. Compartilhamento de Dados

Como não coletamos seus dados, não há compartilhamento de informações com terceiros, anunciantes ou qualquer outra entidade.

4. Exportação de Dados

Você tem total liberdade para exportar seus dados através das funcionalidades de exportação para PDF ou CSV integradas no aplicativo. Esses arquivos são gerados localmente e ficam sob sua responsabilidade.

5. Segurança

Embora os dados sejam armazenados localmente no seu dispositivo, a segurança física e lógica do seu celular é de sua responsabilidade. O RotaLucro aplica melhores práticas de desenvolvimento para garantir a integridade do banco de dados local.

6. Alterações nesta Política

Podemos atualizar nossa Política de Privacidade ocasionalmente. Recomendamos que você revise esta página periodicamente para qualquer alteração.

7. Contato

Se você tiver qualquer dúvida sobre esta política, entre em contato conosco através dos canais oficiais de suporte do aplicativo.
